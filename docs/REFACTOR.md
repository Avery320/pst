# PoC 重構分析與決策

起點為 Rust 導入前的純網頁版本 `ecd543e`，工作分支為 `codex/poc-refactor`。原本的 `main` 保留在 `f4b26fb`。分析與重構日期：2026-10-21。

## 問題判斷

原本的產品範圍適合 PoC：單層項目、固定欄位、少量資料、日曆日期與圖片匯出，不需要排程引擎或後端。日期採 UTC 算天數、輸入邊界驗證與有上限的歷史快照也合理，應保留。

主要架構問題是繪圖底座超出需求，而整合程式持續補足不一致：

| 原實作 | 問題 | 重構結果 |
| --- | --- | --- |
| VTable 的可變 records 與應用文件並存 | 必須複製與同步日期、選取、編輯狀態 | 原生表格與 SVG 只投影目前文件，修改回到同一個提交入口。 |
| 原生拖曳已關閉，仍保留 `resolveChartDates` | 完全沒有生產呼叫，測試卻仍通過 | 刪除該演算法、日期正規化、舊格式轉換與 9 個過期測試。 |
| 直接操作 scenegraph 修補標記文字、選取與里程碑 | 綁定第三方元件內部結構 | 移除整個整合層，使用明確的 SVG 元素與自身座標。 |
| 匯出外掛複製圖表，再另建 Canvas 加標題 | 要處理外掛生命週期、繪圖中更新與捲軸修補 | 從文件產生完整 SVG，再用一個 Canvas 加標題並輸出 PNG。 |
| `model.ts` 同時處理日期、格式、範例、歷史 | 職責混雜，日期與日曆另有重複實作 | 分離日期、日曆、文件與歷史；共用日期驗證和月份邊界。 |
| `app.ts` 同時擁有保存、圖表、側欄、圖示和圖片排版 | 改一個區域容易碰到其他流程 | 分離瀏覽器存取、側欄、圖示與 PNG 產生，控制器只協調流程。 |
| v0.1 樣式後面追加 v0.2 與可讀性覆寫 | 相同選擇器分散，容易殘留無效規則 | 改為一套基礎樣式與明確的響應式區段。 |

## 保留的演算法

| 行為 | 做法 | 成本與理由 |
| --- | --- | --- |
| 天數與星期 | 驗證真實日期，UTC 毫秒換算整天；今天取本地年月日 | 固定成本，避免 DST 與 UTC 日期字串偏移。 |
| 月份與 ISO 週 | 西曆月份夾限、ISO 星期四規則；日期輸入使用原生選擇器 | 不維護自訂月曆格、定位及焦點狀態。 |
| 週一至週五天數 | 完整週乘 5，再檢查最多 6 天 | 固定成本，不推測國定假日。 |
| 拖曳 | 從按下當刻的原日期計算一次位移，對稱四捨五入，最後夾限 | 每次指標更新為固定成本；不累積前一事件的誤差。 |
| 移動與調整邊界 | 整段移動保留日數；調整單端不跨越另一端 | 支援日期邊界與單日里程碑，只保留一套計算。 |
| 繪圖 | 逐日產生表頭與格線，逐列產生圖形；畫面、預覽共用日期座標 | `O(D + N + M)`，D 最多 731 格、N 最多 200 列、M 最多 50 標記，足以直接重繪。 |
| 內容範圍 | 線性掃描項目與標記取最早、最晚日期 | `O(N + M)`，不排序、不建立索引。 |
| 歷史 | 最多 50 個完整快照，用序列化內容判斷是否變更 | 適合目前資料上限，避免 command log、diff、雜湊與同步協定。 |
| 邊緣捲動 | 依邊緣距離與經過時間計算位移，限制單幀時間 | 保留必要的拖曳體驗，沒有額外物理模擬。 |

沒有新增排程、圖論、最佳化、碰撞避讓、資料虛擬化或額外狀態框架。這些都超出目前 PoC 的需求。

## 完整移除的內容

- 舊版圖表實作及其 scenegraph、匯出外掛、捲軸與渲染狀態修補。
- 只供舊版元件使用的日期正規化與 DST／裁切拖曳補正。
- 未使用的短日期函式、重複的本地今天／月底計算及自訂隨機 ID 備援。
- 額外時間軸滑桿、可見日期文字、底部操作與吸附提示、超出範圍提示、裝飾頁尾、標語與側欄提示。
- 已刪除介面對應的事件、計算、圖示與 CSS，不以 `hidden` 保留舊實作。
- 可變列高設定；改為共用的 36px，表格、圖形、拖曳及 PNG 同步縮小。
- 三個直接 VisActor 依賴及其傳遞依賴；lockfile 套件項目由 331 減至 43（包含各平台建置工具），應用執行期依賴為零。
- 不再隨目前建置散發的舊依賴授權清單；歷史版本仍可從 Git 找到。

JSON 的相容性只在輸入邊界處理：缺少日曆設定時補預設，已棄用的 `rowHeight` 視為未知欄位並移除。沒有保留第二套文件、圖表或拖曳實作。

## 共用樣式與第二輪清理

依介面標註，三個側欄分頁改用共用的欄位、雙欄、區塊、開關與捲動類別。文字統一為 12／14／20px，控制項統一 28px，HTML、SVG 與 PNG 的值都來自 `src/presentation/design.ts`。繪圖移到 presentation 層，日期與文件邏輯不依賴樣式。

兩條分隔線合併為 `setupSplitter`，共用鍵盤、指標捕捉、取消、重設與界限計算。移除工作區重複的圖表 resize 呼叫，圖表只觀察自己的容器。桌面使用剩餘視窗高度；窄畫面上下排列，表格與時間軸各自支援原生雙向捲動，垂直維持對齊。

第二輪另移除未被呼叫的月曆清理介面、動態欄位管理、重複的 MutationObserver 刷新、星期長格式分支、未使用的日期格屬性及 ID 前綴清理。後續 review 再以原生日期選擇器取代自訂月曆，側欄與拖曳圖層共用 DOM 建立函式和圖示。API 說明見 [UI 開發規範](UI.md)。

語意引用掃描檢查生產函式／方法的實際呼叫與傳遞，排除僅型別宣告或測試引用；樣式掃描核對 CSS 設計變數、選擇器與標記引用。檢查範圍內沒有發現無生產用途的函式／方法、未定義設計變數、無標記引用的樣式類別或舊繪圖依賴；這些靜態檢查不代表瀏覽器互動已驗收。

## 自適應圖表與預設範圍

移除固定欄寬導致先捲動，以及時間軸固定日寬留下空白的做法。`src/presentation/layout.ts` 先將欄位縮至可讀下限，再允許捲動；時間軸實際日寬至少填滿容器。畫面、拖曳、預覽、捲動中心與 PNG 都取同一份排版結果，不另加 CSS 拉伸或匯出尺寸補正。符合寬度改為將最小日寬設回 1px，刪除應用控制器原有的取整數寬度計算。

新建圖表、範例與隨附 JSON 預設全年和月份表頭。範例項目仍排在當月附近，年底則往前移，確保所有資料都在該年度內；既有文件範圍不覆寫。輸入框聚焦時只改原邊框顏色。表格與時間軸的分隔線、中央握柄已移除，保留透明拖曳區與共用鍵盤操作。

## 驗證與界限

重構前先執行原本 54 個測試並全部通過。移除過期演算法與滑桿後，保留仍有產品呼叫的測試，並補上 SVG 幾何、表頭分組、完整列輸出、文字跳脫及保存失敗情境。

目前有 63 個 Node.js 測試，涵蓋欄位先縮後捲、填滿時間軸與拖曳／匯出共用分數日寬。自訂月曆格演算法移除後，其專用測試也一併刪除。`npm ci`、嚴格 TypeScript 檢查與正式建置也納入驗證。另完成靜態 UI ID 引用與已移除符號／依賴掃描，以及範例和 1900／2100 日期邊界產生的 SVG XML 解析檢查。測試不將標準函式庫的 `structuredClone` 單獨當成專案功能測試；歷史快照的資料隔離仍透過歷史行為驗證。

開發站固定為 `http://127.0.0.1:5175`。使用者要求停止操作網頁後，沒有再做瀏覽器互動驗收。自動測試不能取代最終拖曳、鍵盤焦點、同步捲動、PNG 下載與各瀏覽器外觀驗收，這些項目仍需人工確認。部署依 GitHub Actions 的測試、建置與 Pages 工作完成狀態，搭配公開網址及資產內容核對。

目前保留的限制包括固定欄位、36px 固定列高、文字裁切，以及相近日期標記可能重疊。選擇明確列出限制，避免以更多排版演算法擴張這個階段的維護範圍。
