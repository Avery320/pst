# pst

pst 是規劃中的網頁時程圖表編輯器，目標是讓使用者快速呈現任務、繪製時間軸、製作表格與加入標記，再將完成的版面輸出成圖片或文件，方便放入簡報、報告與工作討論資料。

## 目前狀態

專案目前處於初始化階段，尚未提供可執行的編輯器。以下內容是產品方向與第一版候選功能，實際範圍會在操作原型與技術驗證後確認。

## 產品目標

以容易操作的編輯介面，將任務資訊、日期刻度與視覺標記放在同一份圖表中。使用者能透過拖曳與文字編輯調整內容，並讓表格資料與時間軸上的位置保持一致。

出圖品質也是核心目標，包括清楚的文字、對齊的欄列、可辨識的時段與節點，以及適合簡報和列印的版面。

## 第一版候選功能

- [ ] 新增、編輯與排列任務及資料列。
- [ ] 設定開始與結束日期，顯示日期刻度。
- [ ] 拖曳時段、調整長度與縮放時間軸。
- [ ] 編輯表格欄位、文字內容與欄寬。
- [ ] 使用顏色、標籤、備註與節點標記重點。
- [ ] 調整表格及時間軸的顯示範圍與配置。
- [ ] 儲存、載入與匯入／匯出可繼續編輯的資料。
- [ ] 將表格與時間軸一起輸出；PNG、SVG、PDF 的支援範圍待驗證。

## 技術選型

技術架構與開源底座尚未決定。將優先評估可商用、可修改的既有專案或元件，確認其拖曳操作、表格編輯、標記能力與輸出品質，再決定採用方式。
