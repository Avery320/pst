# pst

輕量的網頁時程編輯器：表格與時間軸逐列對齊，編輯時段、里程碑及日期標記，再匯出完整 PNG。

目前是 PoC，以單機編輯與出圖為範圍，使用原生 HTML 表格、SVG 與 Canvas，沒有後端或帳號。

## 啟動

需要 Node.js 24 以上。

```bash
npm ci
npm run dev
```

開啟 [http://127.0.0.1:5175](http://127.0.0.1:5175)。連接埠被占用時直接報錯，不會自動改用其他連接埠。

```bash
npm run check   # 嚴格 TypeScript 檢查，包含未使用的變數與參數
npm run build   # 檢查並建置到 dist/
npm run preview # 預覽 dist/，同樣使用 127.0.0.1:5175；先停止 dev
```

## 功能

- 時段與里程碑的新增、編輯、複製、刪除及排序。
- 表格雙擊編輯名稱與說明；側欄可編輯全部項目資料。
- 原生日期選擇器、日／週／月表頭、範圍切換、縮放、符合寬度、今天線及週末底色。
- 拖曳移動與調整日期，提供 1 天／7 天吸附、落點預覽及 Escape 取消；放開只提交一次變更。
- 日期標記的新增、編輯與刪除。
- 復原／重做、瀏覽器自動保存、JSON 匯入／下載及損壞資料備份。
- 完整 PNG 匯出，支援 1 倍／2 倍及標題、副標題；包含捲動畫面外的資料。
- 可調整表格分界與側欄寬度；窄畫面上下堆疊。

新建圖表與範例預設顯示當年 1 月 1 日至 12 月 31 日，以月份閱讀。已儲存或匯入文件保留原本範圍；可按「今年」切換全年。

資料列固定為 36px，畫面、拖曳幾何與 PNG 使用同一個列高。表格欄位先縮到可讀下限，時間軸至少填滿可用寬度，超出才以原生捲軸捲動。表格與時間軸之間保留透明拖曳區，焦點只強調原框線。

## 架構

| 位置 | 職責 |
| --- | --- |
| `src/app.ts` | 串接文件變更、歷史、保存、側欄與圖表；所有文件修改走同一條提交路徑。 |
| `src/domain/dates.ts`、`calendar.ts` | 西曆日期驗證、UTC 天數運算、月份、ISO 週及範圍導覽。 |
| `src/domain/document.ts`、`history.ts` | JSON 格式與驗證、範例、內容範圍及最多 50 份歷史快照。 |
| `src/domain/interaction.ts` | 純函式的日期吸附、拖曳、預覽與捲動計算。 |
| `src/presentation/` | 共用設計值、自適應尺寸與 SVG 繪圖；HTML、SVG、拖曳及 PNG 使用同一份排版結果。 |
| `src/ui/` | 原生表格與 SVG、指標事件、側欄及工作區版面。日期輸入由瀏覽器處理。 |
| `src/browser/` | localStorage、檔案下載與 SVG → PNG；不參與日期運算。 |

## 文件與日期規則

JSON 保持 `schemaVersion: 1`，舊文件仍可匯入。既有資料列的內容、日期與顏色保留；舊的 `rowHeight` 欄位會被忽略，統一使用 36px，下載的新文件不再寫入該欄位。缺少的日曆設定補上預設值。

日期使用 `YYYY-MM-DD`，代表日曆日期。所有天數計算都使用 UTC；只有「今天」依使用者的本地日期。起訖日都計入天數，里程碑只佔一個日期。七天吸附相對於原日期，不會強制改為星期一。

日期欄位使用瀏覽器原生選擇器，其外觀、月曆週首及鍵盤操作依瀏覽器與語系設定。圖面的週首設定用於時間軸和「本週」範圍。

支援 1900–2100 年、200 個項目、50 條標記；顯示起訖日期相差最多 730 天。JSON 檔案匯入上限為 1,000,000 bytes。PNG 單邊最多 16,384 像素，總計最多 3,200 萬像素，超過時拒絕匯出並提示縮小範圍或倍率。

自動保存限目前瀏覽器與網站來源，請下載 JSON 備份。損壞的既有內容會先保留原文；備份失敗時暫停自動保存，直到使用者下載原始備份。無法讀取儲存空間時也不覆寫既有內容。

## 已知界限

標記文字靠得太近時可能重疊，沒有自動避讓；表格文字與時間條文字在可用寬度內裁切。這是固定欄位與固定列高的時程出圖工具，沒有任意欄位、依賴排程、資源最佳化、多人協作、自由繪圖或 SVG／PDF 下載。
